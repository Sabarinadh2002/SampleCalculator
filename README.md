# Java Swing Calculator

A fully functional and visually appealing calculator application built using Java Swing. This calculator supports basic arithmetic operations and additional features such as logarithms, square roots, percentages, and more.

## Features

- **Basic Operations**: Addition, subtraction, multiplication, and division.
- **Advanced Functions**:
  - Square and square root calculations.
  - Logarithmic (base 10) calculations.
  - Percentage calculations.
  - Negation of numbers.
  - Use of π (Pi) constant.
- **User-Friendly Design**:
  - Custom rounded buttons for a modern look.
  - Keyboard-style layout for intuitive usage.
  - Dark theme interface for a sleek and elegant appearance.
- **Error Handling**:
  - Division by zero protection.
  - Input validation for invalid or non-numeric values.
- **Backspace and Clear**: Quickly correct inputs or reset the display.

## Technologies Used

- **Java Swing**: For the user interface.
- **Custom Styling**: Custom buttons and borders to enhance UI aesthetics.
- **Java 2D Graphics**: For rendering rounded buttons and borders.

## How to Run

1. Clone this repository to your local machine:
   ```bash
   git clone https://github.com/yourusername/java-swing-calculator.git
2. Navigate to the project directory
   ```bash
   cd java-swing-calculator
3. Compile the Java files:
   ```bash
   javac *.java
4. Run the application:
   ```bash
   java Calculator
